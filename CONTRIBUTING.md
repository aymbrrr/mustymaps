# Contributing

## Code formatting

This project uses Prettier for consistent formatting.

Run:

npm run format

before committing changes if needed.

## Linting

Frontend and backend packages use ESLint.

Frontend ESLint configuration:
packages/frontend/eslint.config.js

Backend ESLint configuration:
packages/backend/eslint.config.js

## Git workflow

Pull the latest changes before starting work.

Keep commits focused and use clear commit messages.

Push changes to the shared GitHub repository and communicate with the team before making major structural changes.

## Project structure

Frontend code belongs in:

packages/frontend

Backend code belongs in:

packages/backend
